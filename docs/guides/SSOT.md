## Documentation Standards

### Writing Style
- **Clear and Concise:** Use simple language, avoid jargon
- **Action-Oriented:** Start with the user's goal
- **Code Examples:** Provide copy-paste ready examples
- **Visual Aids:** Use diagrams and screenshots where helpful

### Document Structure
Each guide should include:
1. **Purpose:** Clear statement of what the guide covers
2. **Prerequisites:** What users need before starting
3. **Step-by-Step Instructions:** Numbered, actionable steps
4. **Examples:** Real-world usage examples
5. **Troubleshooting:** Common issues and solutions
6. **Related Resources:** Links to other relevant docs

### Maintenance
- **Review Quarterly:** Ensure content stays current
- **Version Tracking:** Note which version of Mosaic the guide applies to
- **User Feedback:** Collect and incorporate user suggestions
- **Accessibility:** Ensure guides work for all skill levels
